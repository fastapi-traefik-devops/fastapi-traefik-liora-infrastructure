They are not active agent instructions or operator entrypoints.

[active plan](../IMPLEMENTATION_PLAN.md) for remaining work.

Migration-only scripts remain at their recorded paths. Their resource IDs,
output locations and authorization boundaries belong to the original execution.
Do not rerun them to update a current installation.
